\## User Story



As a beginner who isn't sure where to start, I want to search for exercises by muscle group so that I can build a workout for the body area I want to train. 



\## Acceptance Criterion



Given the exercise library is loaded, when I search for the muscle group "chest", every result shown is tagged "chest" and every chest-tagged exercise in the library appears. 



\## Screen 1 - Home Tab



In the home tab you (the user) are able to view the app's main page to find, create, and view all activities.
